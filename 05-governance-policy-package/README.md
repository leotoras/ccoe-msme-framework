# Component 5 — Governance Policy Package

Adoptable written policy templates for organizations establishing cloud governance without a
dedicated governance function.

Each template is written to be **completed and issued**, not read and admired. Every decision the
adopting organization must make appears in `[SQUARE BRACKETS]`, and each includes an adoption
checklist and a mapping showing which maturity assessment indicators it moves.

## Released

| Policy | Covers | Moves indicators |
|---|---|---|
| [Cloud Access Control and Identity Governance](cloud-access-control-policy.md) | Identity lifecycle, least privilege, MFA, privileged credentials, non-human identities, third-party access, access review | 1.1, 1.3, 2.3, 2.4, 5.1 |

## Planned

- Cloud Data Classification and Handling Policy
- Cloud Change Management Standard
- Cloud Incident Response Plan (SME-scoped)
- Cloud Vendor and Third-Party Risk Standard

## A note on scope

These are deliberately separate documents rather than one combined policy. Combining identity,
data handling, incident response, and acceptable use into a single document produces something
nobody reads and nobody can approve incrementally. Issue them one at a time.

## Important

These templates are starting points, not compliance artifacts. If your organization is subject to
sector-specific regulation — HIPAA, PCI-DSS, CMMC, SOC 2, state privacy law — have counsel or your
auditor review before issuing.
